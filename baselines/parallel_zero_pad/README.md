# Parallel zero-pad NTT comparator

This is the full-length N=1024, p=520193, INT4 comparator discussed in Section IV and plotted as resource ratios in
Figure 3(c), with Cin=1/2/4
and Cout=1. It is distinct from the compact radix-2 baseline in Table I.
The existing source, testbench, two twiddle ROMs, ROM generator, and independent
integer-output checker are included. The simulation checks all 1024 coefficients.

From the repository root, with Vivado 2024.2 in PATH or VIVADO_BIN:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_parallel_zero_pad.ps1
```

The default task is Cin=4, Nh=511, pattern=6. Use `-Cin 1`, `-Cin 2`, or `-Cin 4`
to reproduce 332, 554, or 998 core cycles. The nine archived cases use
(Nh,pattern)=(1,4),(256,0),(511,6) for each Cin. Files generated by a new run are
under `build/parallel_zero_pad`; archived evidence is never overwritten.

The retained implementation flow can be run separately:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_parallel_zero_pad.ps1 -RunImplementation
```

This optional long operation routes at 4.250 ns, then re-evaluates the same
placement/routing at 4.750 ns, matching the archived constraint sequence.
It is not part of the quick check and was not executed for this release.
The paper uses 4.750 ns (210.526 MHz) for this comparator's latency. The 4.250 ns
power estimate is not promoted into a paper performance comparison.

## Provenance

`SOURCE_PROVENANCE.json` records original and distributed hashes. Five source
files have only absolute ROM path prefixes replaced by `.`; arithmetic and
scheduling are unchanged. Other source and testbench bytes are unchanged.
The script copies ROMs into its build workspace so these relative paths resolve.

Unlike the FACT core, this older comparator did not retain a routed-source hash
manifest. A matching coefficient/cycle smoke test does not prove byte identity
with the old routed netlist. Archived route values remain explicitly archived;
a fresh implementation may differ. This qualification does not apply to the
51 retained, manifest-pinned FACT source files.
